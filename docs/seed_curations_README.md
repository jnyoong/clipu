## 실행 방법 (Supabase SQL Editor)

### 1단계: SQL Editor 열기

1. [Supabase 대시보드](https://supabase.com/dashboard) 접속
2. **clipu 프로젝트** 선택
3. 좌측 메뉴 → **SQL Editor** 클릭
4. **"New Query"** 버튼 클릭

### 2단계: SQL 파일 내용 붙여넣기

파일 경로: `docs/seed_curations_FULL.sql`

전체 내용을 복사해 SQL Editor에 붙여넣으세요.

### 3단계: 실행

- **Run** 버튼 클릭 (또는 Ctrl+Enter)
- 완료까지 약 10~30초 소요

### 4단계: 결과 확인

SQL Editor에서 아래 쿼리로 확인:
```sql
-- 컬렉션 수 확인
SELECT category, COUNT(*) FROM collections WHERE is_public = true GROUP BY category;

-- 링크 수 확인
SELECT COUNT(*) FROM links l
JOIN collections c ON l.collection_id = c.id
WHERE c.is_public = true;

-- 에디터 계정 확인
SELECT email FROM auth.users WHERE email = 'editor@clipu.app';
```

## 주의사항

- SQL을 **두 번 실행**하면 에디터 계정 중복으로 오류가 발생할 수 있습니다 (컬렉션/링크는 UUID 자동 생성이라 중복 없음)
- 에디터 계정은 Supabase Auth → Users에서도 확인/관리 가능
- 어드민 페이지(admin.html)에서 공개 클립 숨김 처리 가능
